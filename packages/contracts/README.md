# contracts

Мовно-нейтральні контракти між сервісами. JSON Schema фіксує спільний формат незалежно від мови. Поточний Python consumer перевіряє підтриману версію та raw_item_id і читає зміст із БД; повна runtime JSON Schema-валідація ще не підключена. API сайту не є споживачем NATS.

- `events/<subject>.v<N>.schema.json` — події в NATS. Subject = назва файла без версії. Несумісна зміна — нова версія поруч, стара живе, доки є споживачі.
- HTTP-контракт `apps/api` (OpenAPI) з'явиться тут, коли стабілізуються маршрути стрічки та інцидентів.
- Схема БД — у [`db/migrations`](../../db/migrations).
