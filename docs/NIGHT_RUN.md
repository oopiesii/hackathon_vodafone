## Межі, які не перетинати без користувача

- **Production.** Розгортати лише якщо сесія має доступ до Docker **і** користувач це явно дозволив перед сном (див. «Режими» нижче). Тоді — за правилами §0 плану: образи для відкату до, перевірка після, автоматичний відкат при будь-якій невдалій перевірці. Collectors перезапускати щонайбільше один раз і не пізніше 04:45. Ніколи `down -v`, ніколи правок застосованих міграцій, ніяких змін поза блоком Vodafone у спільному Caddy.
- **Дані.** У публічний сервіс не потрапляє непозначена синтетика. Перевірки — на `ufv_checks` або підставному API.
- **Модель.** У LLM — лише джерела з `llm_allowed=true`. Для Telegram прапорець не вмикати: це рішення користувача.
- **Секрети.** Нічого з `/etc/ufv`, `var/`, сесій і ключів — у Git, журнали чи знімки.
- **Git.** Коміти локально — так. `push` — лише якщо користувач дозволив; без примусового перезапису історії.
- Не видаляти й не переписувати чужі зміни; конфлікт із паралельною сесією — зупинити цей пункт, записати в STATUS, узяти наступний.
