# Монітор бренду Vodafone Україна

Дашборд скарг на мережу, інтернет і сервіси Vodafone у соцмережах та ЗМІ.
Зараз це **статичний знімок від 19.09.2026** на реальних даних з відкритих джерел.

Дві вкладки:

- **📊 Дашборд** — попередній вигляд без змін: критичний інцидент, статистика, стрічка згадок, відсіяний шум.
- **🤖 AI-аналітик** — чат, де можна вільним текстом запитати звіт (без окремих кнопок для кожного випадку). Розпізнає 4 конкретні теми за ключовими словами — «що сталося за останню добу», «головні ризики», «теми, що набирають популярність», «що роблять конкуренти» — а будь-яке інше формулювання (напр. «зроби звіт», «що у нас на дашборді») за замовчуванням дає загальний аналіз усього поточного дашборду одразу, а не «не зрозумів». Усе рахується наживо з `mentions`/`filtered` у `data.js`, без зовнішніх LLM-викликів і без збереження тексту; якщо за період нічого не сталося або даних замало — звіт каже про це прямо, а не вигадує висновок.

## Як відкрити

- **Локально:** просто відкрийте `index.html` у браузері. Сервер не потрібен.
- **Онлайн для команди:** GitHub Pages (див. нижче).

## Структура

| Файл | Що там | Хто редагує |
|---|---|---|
| `index.html` | Вигляд, графіки, логіка, вкладка AI-аналітика (розпізнавач намірів + генератори звітів) | Розробник |
| `data.js` | Згадки, відсіяний шум, перегляди постів, `SNAPSHOT_DATE` | Аналітик |
| `.env.example` | Шаблон ключів API | — |

### Як розширити AI-аналітик

- Нову тему запиту додають у `classifyIntent()` (regex ключових слів) + окрему `report*()`-функцію, яка повертає HTML-рядок з даних `data.js`.
- Якщо колись підключати справжній LLM API — ключ ніколи не в `index.html`/`data.js`; лише `.env`/Secrets, як і для інших джерел (див. розділ «Секрети» нижче).

Щоб додати нову згадку, допишіть об'єкт у масив `mentions` у `data.js`:

```js
{d:"2026-09-20", sev:"m", cat:"net", src:"Threads",
 what:"Коротко: що сталося", url:"https://...", site:"threads.net"},
```

`sev`: `h` критично · `m` середній · `l` низький
`cat`: `net` мережа · `cov` покриття · `bill` списання · `tariff` тарифи · `sup` підтримка

## GitHub Pages

1. Settings → Pages → Source: **Deploy from a branch** → `main` / `root` → Save.
2. За хвилину-дві сайт буде на `https://<ваш-логін>.github.io/<назва-репо>/`.

Зауважте: на безкоштовному плані GitHub Pages працює лише для **публічних** репозиторіїв.
Для приватного репо з Pages потрібен план Pro / Team.

## ⚠️ Секрети

Токени Threads, Instagram і Telegram зберігайте **тільки** в `.env` (він у `.gitignore`)
або в Settings → Secrets and variables → Actions. Ніколи не вписуйте їх у `index.html`
чи `data.js` — у публічному репо їх побачать усі, а Meta відкличе доступ.

## Джерела даних

| Джерело | Статус | Як підключити | Обмеження |
|---|---|---|---|
| Telegram | ✅ у знімку | Telethon + `TG_API_ID/HASH` з my.telegram.org | Коментарі видно лише через API, дизлайків немає |
| ЗМІ | ✅ у знімку | RSS / вебпошук | Перевіряти дату на самій сторінці |
| Threads | ❌ | `/keyword_search`, App Review у Meta | 500 запитів за 7 днів |
| Instagram | ❌ | Hashtag Search, App Review у Meta | 30 хештегів за 7 днів, без Stories і тексту |
| X | ❌ | X API (платний) | Залежить від тарифу |
