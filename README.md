# hackathon_vodafone

**Vodafone: AI Reputation & Crisis Intelligence** — хакатонний проєкт для раннього виявлення репутаційних сигналів і підготовки AI-брифу з доказами.

Поточний етап: **збір вимог**. Команда — 7 учасників. Стек, остаточний MVP і строки ще не затверджені; реалізацію не розпочато. Робоча оцінка часу — 1–2 дні, тоді як умови містять орієнтир у 6 годин. Це треба уточнити.

Погоджені представлення продукту: стрічка публікацій із фільтрами та інциденти, які об'єднують пов'язані матеріали, розвиток ситуації й докази. Основний кандидат MVP — виявлення потенційних криз + AI-бриф.
