# Vodafone: AI Reputation & Crisis Intelligence

Тестовий Telegram-модуль платформи моніторингу українського телекому. Сайт: **https://hire.qpon**. Публічний вхід закритий; облікові записи створює адміністратор.

Збережено каркас команди: TypeScript / Hono / Better Auth / Kysely, React / Vite / TanStack Query, PostgreSQL та NATS. Реалізовано окремі Python-процеси Telethon і processor. Інтерфейс — нейтральна ділова дизайн-система на зразок shadcn/ui (`apps/web/src/styles`, `components/ui.tsx`); початковий макет `vodafone-monitor/vodafone-monitor` збережено як історичний.

## Що вже працює

- Авторизація, ролі, керування користувачами, зміна пароля.
- Адмін: workflow, увімкнення/вимкнення збору, автоматичне підключення Telegram-сесій із CLI, додатковий імпорт і заміна ключів, призначення сесії каналу.
- Пости й коментарі: історія, події наживо, контекст відповідей, збережені позиції збору, повторні спроби, точна дедуплікація.
- Нормалізована стрічка, пошук, фільтри, оригінал джерела й часові мітки; сумнівні матеріали перевіряє адміністратор.
- Посилання на зведення, лише пости або пости з коментарями; обмеження workflow/каналами/темами, строк дії та відкликання.

Фільтрація зараз працює **за правилами**, без LLM. Інциденти, AI-бриф і прогнозування ще не реалізовані. Telegram-модуль початково вимкнений. Перевірки використовують синтетичні матеріали в окремій базі; першу справжню сесію підключено. Окремий публічний канал уже читається: один пост отримано й відсіяно правилами. Супергрупи як самостійні джерела ще не підтримуються; повний сценарій коментарів ще не перевірено. Повнота збору й точність фільтра не виміряні.
